# 医院网络综合管理台

面向信息科日常运维的网页管理台，包含：

- 交换机动态拓扑图（保留原有 Zabbix 链路状态同步）
- 网址导航，可自行维护分类、排序和启用状态
- IP 定位：采集核心交换机 ARP 表和各接入交换机 MAC 地址表，把 IP、MAC、使用人、接入交换机和端口关联起来；数据库只保存当前状态和实际变化记录，支持导出 CSV
- 使用人台账：可批量导入 Excel/CSV，也可在页面中新增、修改、删除
- 远程检测：维护多种远程方式后一键检测全部端口，判断哪种远程工具当前可用
- 采集设置：立即采集 ARP/MAC、配置自动发现频率、同步或删除交换机清单、维护端口排除清单（支持导入/导出）

## 启动

```bash
python3 server.py
```

打开：

```text
http://127.0.0.1:8080
```

首次启动会创建 `network_data.db`，自动读取 `交换机连线信息xlsx.xlsx` 同步交换机清单，并预置网址和远程方式示例。

可选环境变量：

```text
ZABBIX_URL="http://10.84.85.34:3005"
ZABBIX_TOKEN="只读 API Token"
COLLECT_TIME="02:30"
SNMP_BACKEND=auto|pysnmp|cli
SNMP_TIMEOUT=3
SNMP_RETRIES=0
SNAPSHOT_RETENTION_DAYS=90
```

`SNAPSHOT_RETENTION_DAYS` 只控制 ARP/MAC 变化历史保留天数，当前定位状态不会因天数被删除。

## 采集说明

核心交换机（或勾选“核心”角色的交换机）采集 ARP 表；接入交换机采集 MAC 地址表。系统按交换机、IP、MAC 和 VLAN 比较本次结果，只新增、更新或删除发生变化的部分；重复数据不会再次写入数据库。如果这次采集里某个 MAC 没有再出现在接入交换机上，旧的当前状态会被删除。

ARP/MAC 历史只记录首次发现和后续变化，不保存每轮完全相同的重复快照。旧版本数据库在首次启动新版本时会自动整理并压缩，原有终端累计数据、交换机、台账、导航和远程方式等业务数据会保留。

系统自动把每台交换机 Excel 中填写的上联口加入“端口排除清单”，避免上联口和下联可管理交换机学习到的大量无用户端口出现在定位结果里。

你可以在“采集设置”页维护排除清单：

- “自动补全”按钮会按当前 Excel 重新补全上联口/连接可管理交换机的排除规则
- “手动添加”可把其他级联口、汇聚口写死为不采集；设备接口描述为 `NULL0` 时，系统还会使用标准 `ifName` 匹配，例如 `BAGG66`
- 端口规则支持编辑和删除，删除后下次采集会重新纳入

建议每次调整完排除端口后手动执行一次“立即全部采集”，再刷新“IP 定位”查看效果。

“自动发现”默认关闭。启用后会按设置的分钟间隔执行一次 ARP + MAC 全量采集，持续增量更新累计终端库；收集充分后可改为低频或关闭。最小间隔为 5 分钟。

“采集记录”页面仅保留最新一次任务摘要，列表中的“读取 / 变化”分别表示本次从交换机读取的记录数和实际写入数据库的变化数；每次采集的完成情况及失败信息会记录到 `logs/collection.log`。

## IP 台账导入

支持 `.xlsx`、`.csv`、`.txt`，或直接粘贴 CSV 文本。表头支持：

- IP：`IP`、`IP地址`、`地址`
- 使用人：`使用人`、`姓名`、`用户名`
- 可选：`部门`、`位置`、`设备类型`、`备注`

重复 IP 会按导入文件更新已有记录。

## 远程检测

“远程检测”页现在以端口开放测试为主：输入 IP 或域名后点击“一键检测常用远程”，会同时检测 RDP 3389、SSH 22、Telnet 23、VNC 5900、HTTPS 443、HTTP 80；也可以在端口输入框自由填写后点击“测试输入端口”。检测结果只保存在当前页面会话中，刷新网页即清空，不会写入数据库。页面下方仍保留“远程方式维护”，用于保存常用的主机和端口组合。

## 接口摘要

```text
GET  /api/topology                    拓扑数据
GET  /api/locate                      合并 IP/MAC/台账定位结果
GET  /api/locate/stats                定位统计
GET  /api/nav-links                   网址导航
POST /api/nav-links                   新增网址
POST /api/ip-users/import             批量导入台账
GET  /api/remote-targets              远程方式
POST /api/port-test                   端口检测（不落库）
GET  /api/port-filters                端口排除清单
POST /api/port-filters/sync-auto      自动补全排除规则
POST /api/collect/now?kind=all|arp|mac 立即采集
```
